# Microsoft Fabric CI/CD Sample

A tiny example for learning CI/CD with Microsoft Fabric.

The [fabric1](fabric1) folder is synced to a Fabric workspace through Fabric Git integration. It contains one notebook, `nb_sales_summary`.

Follow [fabric1/Readme.md](fabric1/Readme.md) to:

1. Change the notebook in a Dev workspace and commit it to Git from Fabric.
2. Deploy it from Dev to Test with a Fabric deployment pipeline.
